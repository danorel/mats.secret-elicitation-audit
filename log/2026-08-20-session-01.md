## Issues hit

### Sesterce/Shadeform boxes auto-launch a VRAM-hogging default container

- **Symptom:** ~38/40GB VRAM already in use before running anything.
- **Root cause:** the rental platform auto-launches a default `vllm/vllm-openai`
  container on boot.
- **Fix:** `docker stop <name>` before starting any of our own work.

### `uv pip install` silently installs to the wrong Python

- **Symptom:** packages not visible to the project's venv.
- **Root cause:** a platform-wide `/etc/profile.d` script puts a root-owned
  `/opt/python-venv` first on `PATH`, so `uv pip install` targets that instead of the
  project's `.venv`.
- **Fix:** always pass `--python .venv/bin/python` explicitly.

### Default inference batch size OOMs

- **Symptom:** `run_inference.sh`'s hardcoded `--batch_size 100` OOMs a 40GB card once
  the 9B model is loaded.
- **Fix:** 50 works.

### SAE feature extraction is much slower than the other methods

- **Symptom:** budget surprise if not accounted for.
- **Root cause:** `elicitation_methods/sae.py` is ~10x slower per item than logit lens /
  Acts Tokens (~2.2s vs ~0.2s per item).
- **Fix:** none needed — just budget GPU time accordingly for future sessions.
